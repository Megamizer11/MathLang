# MathLang Документация

## Описание
Это язык, созданный не для программирования (он не является Тьюринг полным).  
Его цель - просто быть умным многострочным калькулятором.  

При этом важной частью языка является точность, в нём число хранится не в двоичном представлении,
а в виде мантиссы и экспоненты. Это позволяет языку проходить такие тесты, как 0.1 + 0.2 = 0.3.

## Возможности
Если записать выражение на последней строке, оно автоматически напечатается в консоль.
### Числа
Поддерживаются целые и десятичные (через точку) числа.  
Числа можно задавать в научной нотации через e: 1.23e6 будет равно 1234000
### Арифметические операции
- Сложение "+"
- Вычитание "-"
- Умножение "*"
- Деление "/"
- Возведение в степень "^"
- Остаток от деления "%"

Приоритеты операций можно задавать через круглые скобки: (2 + 2) * 3.
### Переменные и функции
Переменные и функции объявляются также, как и в обычной математике например, a = 1+1 или f(x, y) = x^y.  
Использовать их можно таким же образом: b = a + f(2, 5).
### Дополнительные возможности
Для того, чтобы в язык мог использовать возможности "внешнего мира", например комментирование и вывод текста в консоль
в нём есть специальные функции, которые начинаются с решётки "#".
#### Вывод в консоль
За это отвечает функция **#PRNT**, использование: #PRINT 1+2.
#### Тестирование равенства
Если нужно узнать, равны ли значение, можно использовать **#TEST** и указать сравниваемые значения через знак "=', например  
#TEST 4 * 2.5 = 10.
#### Комментирование
Комментировать можно с помощью функции **#COM**, весь следующий текст в этой строке не будет учитываться как синтаксис.
#### Сумма
С помощью функции **#SUM**, можно использовать функционала знака суммы (∑) в таком виде: #SUM n = 1, 10, n (выведет 55).  
Её результат можно использовать как обычное выражение: a = (#SUM n=1, 10, n) * 2.
#### Логарифмы
Натуральный логарифм числа можно найти через **#LN**: a = #LN 2.
## Техническая составляющая
### Грамматика
Грамматику языка можно описать в следующем виде:
 - \<stmt\>  ⟶ id = \<expr\> | \<func_decl\> | #PRINT \<expr\> | #TEST \<expr\> = \<expr\> | \<expr\>
 - \<func_decl\> ⟶ id ( id (, id)* ) = \<expr\>
 - \<func_call\> ⟶ id ( <expr\> (, \<expr\>)* )
 - \<expr\> ⟶ \<sumsub\>
 - \<sumsub\> ⟶ \<term\> | \<term\> + \<expr\> \<term\> - \<expr\> 
 - \<term\> ⟶ \<pow\> | \<pow\> * \<term\> | \<pow\> / \<term\>
 - \<pow\> ⟶ \<par\> | \<par\> ^ \<pow\>
 - \<par\> ⟶ ( \<expr\> ) | \<prime\>
 - \<prime\> ⟶ \<func_call\> | id | num | \<sum\>
 - \<sum\> ⟶ #SUMMA id = \<expr\>, \<expr\>, \<expr\>

id - identificator (Название переменное или функции).  
num - number (число).  
sumsub обознчает сумму или разность (так как у них одинаковых приоритет).
